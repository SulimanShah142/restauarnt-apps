# OneSignal v5 Push Notification Fix - Complete Guide

## Problem Summary

The app was showing this error:
```
ERROR  [OneSignal] ⚠️ Could not add event listener: [Invariant Violation: Must provide a valid callback]
```

And **no push tokens were being generated** because:
1. OneSignal v5 requires `optIn()` to be called explicitly
2. Tokens need time to be generated by Firebase/APNs
3. The code wasn't waiting for tokens before trying to sync them

## What Was Fixed

### 1. Updated OneSignal Initialization (All 3 Apps)

**Files Changed:**
- `userapp/utils/onesignal.ts`
- `deliverapp/utils/onesignal.ts`
- `admins-app/utils/onesignal.ts`

**Key Changes:**
```typescript
// ✅ NEW: Added optIn() call
export async function initializeOneSignal() {
  OneSignal.initialize(ONESIGNAL_APP_ID);
  
  // Request permission
  const granted = await OneSignal.Notifications.requestPermission(true);
  
  // CRITICAL: Opt in to push notifications (required in v5)
  OneSignal.User.pushSubscription.optIn();
}
```

### 2. Added Token Waiting Logic

The code now polls for up to 60 seconds waiting for tokens to be ready:

```typescript
async function waitForOneSignalTokens() {
  for (let i = 0; i < 120; i++) { // 60 seconds
    await new Promise(resolve => setTimeout(resolve, 500));
    
    const { onesignalId, pushToken, subscribed } = getOneSignalSubscription();
    
    if (onesignalId && pushToken && subscribed) {
      return { onesignalId, pushToken };
    }
  }
}
```

### 3. Added Expo Push Token Support

Now generates **both** OneSignal and Expo push tokens:

```typescript
export async function getExpoPushToken() {
  const { data } = await Notifications.getExpoPushTokenAsync({
    projectId: 'your-expo-project-id', // ← You need to add this!
  });
  return data || null;
}
```

### 4. Updated Login Flow (All 3 Apps)

**Files Changed:**
- `userapp/app/(auth)/sign-in.tsx`
- `deliverapp/app/(auth)/sign-in.tsx`
- `admins-app/app/admin/login.tsx`

**Key Change:**
```typescript
// After successful login:
await syncOneSignalTokens();
```

## Troubleshooting

### Problem: `pushToken` is still `null`

**Solution:**
1. Check Firebase is configured correctly
2. Verify SHA-256 fingerprint is added
3. Make sure you're running on a **physical device** (emulators don't get push tokens)
4. Rebuild the app after Firebase config changes

### Problem: `onesignalId` is `null`

**Solution:**
1. Make sure `optIn()` is called
2. Check OneSignal App ID is correct
3. Verify notification permission was granted

### Problem: Error "Must provide a valid callback"

**Solution:**
This was fixed by:
1. Making `initializeOneSignal()` async
2. Awaiting `requestPermission()`
3. Adding try-catch blocks

### Problem: Tokens not syncing to database

**Check:**
1. User is logged in when `syncOneSignalTokens()` is called
2. Database tables exist with correct columns
3. RLS policies allow updates

## Database Schema Reference

Make sure you have these tables:

```sql
-- profiles table
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  email TEXT,
  full_name TEXT,
  onesignal_player_id TEXT,
  expo_push_token TEXT,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);

-- onesignal_players table
CREATE TABLE onesignal_players (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  onesignal_player_id TEXT,
  app_type TEXT, -- 'user', 'delivery', or 'admin'
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(user_id, app_type)
);
```
